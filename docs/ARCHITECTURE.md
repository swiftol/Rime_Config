# 项目架构

Rime 中日直输不是单一词库或配置备份，而是一套面向 Windows 的输入法发行版。

```text
Windows 应用输入框（TSF）
          │
          ▼
修改版 Weasel 前端 ───── 候选窗布局、颜色、滚动、按键预览
          │
          ▼
修改版 librime + Lua ─── 中日候选合并、排序、注释、模糊匹配
          │
     ┌────┴────┐
     ▼         ▼
中文/英文词库  日语词库与读音
     │         │
     └────┬────┘
          ▼
离线候选与翻译注释
```

## 主要组件

### Rime 方案与词库

仓库根目录的 schema、`cn_dicts`、`dicts` 和 `en_dicts` 定义中文、日语、英文候选及公共翻译注释。用户学习数据不属于项目源文件，也不进入发布包。

### Lua 候选管线

[`lua`](../lua) 中的组件负责日语前缀候选、模糊匹配、候选语言识别、排序和读音预览等高层行为。方案引用的每一个 Lua 模块都会在打包和安装后验收中检查。

### 修改版 Weasel

[swiftol/weasel](https://github.com/swiftol/weasel) 提供候选窗扩展，包括单行紧凑布局、展开滚动、动态候选宽度、中日配色、注释对齐和 Shift/空格/Alt 读音预览。

### 图形化设置程序

[`src/RimeSettings`](../src/RimeSettings) 是独立桌面应用，用于修改注释、输入按键、模糊匹配、外观、常用语和过滤门槛。仅影响界面的设置采用轻量刷新；词库或方案结构变化才触发完整部署。

### 安装器与诊断

[`installer`](../installer) 负责部署修改版运行时、迁移历史版本、备份用户配置、保留个人数据、显示编译进度并运行安装后验收。诊断工具区分“独立引擎可用”和“真实 Windows TSF 会话可用”。

## 数据边界

公共配置、公共词库和预生成注释可以发布。个人词频、常用语、剪贴板、同步数据、日志、机器标识和本机路径必须留在用户电脑上。详细规则见 [隐私说明](./PRIVACY.md)。
