# 中日输入法 2.1.0

本次重点更新自定义日语双拼、保留字与整串转换，并改进学习模式、设置热切换和候选布局。

## 新功能

- 自定义日语按键表：可编辑普通/Shift 层、声母、韵尾与独立空声母键，导入、保存和切换方案；新增实验性元音起始韵尾简拼开关。
- 保留字：支持分组、启用状态筛选，以及在搜索结果中直接启用/停用；支持多个读音和组合输入。
- 整串交给 Mozc：将按键和保留字还原出的完整读音统一转换，保留旧路径开关，减少逐词硬拼带来的错误。
- 多规则日语模糊匹配：独立开关，最多组合三步已开启的规则；不开启时保留原有纠错行为。
- 学习模式：可在词语和假名后追加空格或文本换行；换行不模拟 Enter，不触发聊天发送。
- 中日候选分栏：左中文、右日文，可调左右列数；首行随词长布局，空余位置借用另一侧候选，纯单语后续行不保留多余分隔线。
- 命名总配置与热切换：保存常用开关、外观、快捷键等可分发设置，无需每次重启或重新部署词库。
- 键盘编辑：可配置候选展开、翻行和翻页按键。
- 回车提供原文、首选、首选加 Enter、原文加 Enter 四种行为；应用 Enter 与文本换行分开处理。

## 修复与改进

- 调整日语模糊匹配排序，优先显示完整词典匹配，减少不相关的延伸候选。
- 修复保留字组合被过滤、中文精确匹配误用日语读音、无关自动 emoji 占位等问题。
- 修复日语纠错读音的右括号缺失，以及保留字、纠错颜色显示异常。
- 改进 Shift 读音预览、展开数字选词映射、长句换行、分栏与注释对齐。
- 外观调整即时保存，注释字号与候选宽度独立处理。
- 中日逗号随当前选中候选区分：中文候选使用“，”，日语候选使用“、”；保留按键表的标点映射与 ASCII 标点选项。
- 改进测试台版本提示，方便确认当前测试的版本；保留原窗口和草稿。

## 默认设置与升级

新安装采用本次整理的按键方案、保留字分组、学习模式、外观和分栏设置；升级保留已有个人配置。

升级后，请保存内容并重新打开正在使用的应用，以使用新版输入法。
