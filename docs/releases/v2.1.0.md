# 中日输入法 2.1.0

本次重点更新自定义日语双拼、保留字与整串转换，并改进学习模式、设置热切换和候选布局。

## 新功能

- 自定义日语按键表：可编辑普通/Shift 层、声母、韵尾与独立空声母键，导入、保存和切换方案；新增实验性元音起始韵尾简拼开关。
- 保留字：支持分组、启用状态筛选，以及在搜索结果中直接启用/停用；支持多个读音和组合输入。
- 整串交给 Mozc：将按键和保留字还原出的完整读音统一转换，保留旧路径开关，减少逐词硬拼带来的错误。
- 多规则日语模糊匹配：独立开关，最多组合三步已开启的规则；不开启时保留原有纠错行为。
- 学习模式：可在词语和假名后追加空格或文本换行；换行不模拟 Enter，不触发聊天发送。
- 中日候选分栏：左中文、右日文，可调左右列数；首行随词长布局，空余位置借用另一侧候选，纯单语后续行不保留多余分隔线。
- 命名总配置与热切换：保存常用开关、外观、快捷键等可分发设置，无需每次重启或重新部署词库。
- 键盘编辑：可配置候选展开、翻行/翻页相关按键，不必依赖鼠标滚轮；对应已解决的 Issue #4。
- 回车提供原文、首选、首选加 Enter、原文加 Enter 四种行为；应用 Enter 与文本换行分开处理。

## 修复与改进

- 完整词典纠错优先于延伸和未证实的拼接猜测，不针对单个词硬编码置顶；仍保留原输入的精确词和模型原首选。
- 修复保留字组合被过滤、中文精确匹配误用日语读音、无关自动 emoji 占位等问题。
- 修复日语纠错读音右括号与变色元数据，保留字和纠错颜色不再被内部标记破坏。
- 改进 Shift 读音预览、展开数字选词映射、长句换行、分栏与注释对齐。
- 外观调整即时保存，注释字号与候选宽度独立处理。
- 中日逗号随当前选中候选区分：中文候选使用“，”，日语候选使用“、”；保留按键表的标点映射与 ASCII 标点选项。
- 测试台增加版本与已加载组件提示：版本一致不等于功能已经验收；旧窗口和草稿无需被强制关闭。

## 本次公开设置

按维护者当前配置制作安装默认值：包含当前按键表、保留字及分组、配置库、热设置、学习输出选项、外观和分栏偏好。新安装使用这套默认值；升级时保留已存在的个人配置。

**不包含 API 密钥、账号标识、DPAPI 密文、个人词频/学习记录、输入历史、剪贴板或历史备份。** 云服务需要使用者自行配置。升级后仍已打开的应用可能继续加载旧输入法组件，请保存内容后自行重新打开相应应用；不要把后台已更新理解成旧应用内存组件已经替换。

## 验证范围

本轮排序和开关回归 54 项、保留字及数字选词 120 项通过；100 条常用句审计全部找到，其中 99 条在前三。安装后台复核了保留字、中文召回、纠错括号与长按输入。另在空白用户目录验证了发布载荷的部署及候选，并验证默认设置不覆盖已有偏好。

这些是隔离模型/提交或后台检查，不冒充所有真实应用的 TSF 回调和最终画面验收；也不表示所有日语表达均已正确。欢迎继续反馈可复现输入和预期候选。
